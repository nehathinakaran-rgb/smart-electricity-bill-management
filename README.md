## Project Description

The Smart Electricity Consumption and Bill Management System is a Java-based application designed to simplify electricity consumption calculation and electricity bill management.

The system calculates electricity units consumed using previous and current meter readings, generates bills based on predefined electricity tariff rates, and stores meter readings and bill details for future reference.

The project aims to reduce manual calculation errors, save time, maintain organized billing records, and allow users to view current and previous electricity bills.

## Technologies / Tools Used

- **Programming Language:** Java
- **GUI Development:** Java Swing

- **Database Connectivity:** JDBC
- **Query Language:** SQL

## Main Features

- User registration and login
- Customer details management
- Meter reading entry
- Automatic electricity consumption calculation
- Electricity bill generation
- Billing record storage
- Previous bill history
